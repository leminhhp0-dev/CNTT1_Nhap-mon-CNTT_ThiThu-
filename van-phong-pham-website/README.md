# Văn phòng phảm
Nơi mua sắm **đồ dùng học tập** và **đồ gia dụng** *uy tín chất lượng số 1*
## Quy mô hàng hoá
|Thư mục|Nội dung|
|:---:|:---:|
|Đồ dùng học tập|Bút, vở, cặp,...|
|Đồ gia dụng|Pin, móc khoá, băng dính,...|
## Quy trình nhập hàng mới trong ngày
Mỗi lần hết ngày làm việc cần kiểm tra và trước khi ghi đè lịch sử nhập hàng cũ để nhập hàng mới
```Bash
gc nhap_hang.txt
echo "Hoá đơn" > nhap_hang.txt
```
## Công việc trong ngày
- [x] Nhập hàng
- [ ] Cập nhật hoà đơn
- [ ] Bóc xếp
